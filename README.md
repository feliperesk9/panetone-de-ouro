# 🎄 Panetone de Ouro™ - Landing Page de Alta Conversão

Landing page de alta conversão para o curso digital **Panetone de Ouro™: O Método Prático para Faturar de R$ 3.000 a R$ 5.000 com Panetones Lucrativos no Natal**.

---

## ✨ Características do Projeto
- **Nova Identidade Visual:** Cores nobres (Vinho Borgonha, Dourado Ouro, Marfim e Verde Esmeralda).
- **Copywriting Persuasivo:** Focado em renda extra rápida para iniciantes, quebra de objeções e alta margem de lucro.
- **Estrutura Completa de Conversão:**
  - Hero section de alto impacto com foto da especialista
  - Comparativo Problema vs. Solução
  - Grid com os 4 módulos detalhados
  - Depoimentos autênticos com fotos e avaliações 5 estrelas
  - Card de oferta com ancoragem (De R$ 97 por R$ 19,90)
  - Selo de garantia incondicional de 7 dias
  - Seção da especialista (Chef Fernanda Rodin)
  - FAQ interativo com accordion
  - Notificação flutuante de prova social dinâmica
- **100% Responsivo:** Otimizado para celular, tablet e desktop.
- **Zero Dependências Pesadas:** HTML5, CSS3 moderno e Vanilla JavaScript.

---

## 🚀 Como Executar Localmente

### Opção 1: Direto no Navegador
Basta abrir o arquivo `index.html` com dois cliques em qualquer navegador.

### Opção 2: Com Servidor Local Node.js
```bash
node server.js
```
Acesse em: [http://localhost:3000](http://localhost:3000)
